# Crumbly

Crumbly is a recipe sharing and discovery website developed for the
IMS207 / IMS301 Web Design and Internet Programming course
(project A1 - Recipe Sharing Site).

Users can browse recipes, search by ingredient, share their own recipes
with photos and comment on recipes. Only the owner of a recipe (or an
admin) can edit or delete it.

## Technologies

HTML5, CSS3, vanilla JavaScript, PHP 8+, MySQL (PDO)
